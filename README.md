<br/>

## 📝 작품소개

.NET 기반의 크로스 플랫폼 프레임워크인
 .NET MAUI 기반의 수어 통번역 시스템을 개발하였습니다.
 시스템을 통해 청각/언어 장애인의 불편함을 개선하고, 
수어 통역사 부족 문제를 해결하여 의사소통을 원활하게 
할 수 있는 기능을 제공합니다.

<br/>

## 🌁 프로젝트 배경
 - 의료 수어 통역 서비스가 원활하지 않음
 - 아픈 증상에 대한 설명에 어려움을 겪음
 - 의료진과 소통이 어려워 진료시간이 증가


<br/>
